# Nexora
## About
Nexora is a simple web application where you can test your geography skills by guessing the countries from the given clues or the flags. It has two modes here which are listed below: 
- By Clues: You get 3 clues and whenever you take minimum possible clues, you get more points if you guess it right.
- By Flags: You submit a mini form then a flag comes up in the screen according  to your input, you need to guess the flag and write it in a given input box where you can submit from clicking 'Enter'.
